4. Imbalance Ratio (IR)

IR = 190.9380

O Imbalance Ratio representa a razão entre a quantidade de observações da classe majoritária e a quantidade de observações da classe minoritária.

Quanto maior o valor do IR, maior é o desbalanceamento entre as classes.

5. Entropia de Shannon

Entropia = 0.047012 bits

Para uma variável binária, a Entropia de Shannon varia entre 0 e 1.

  • Valores próximos de 0 indicam maior concentração das observações em uma única classe.
  • Valores próximos de 1 indicam maior equilíbrio entre as classes.

6. Distribuição das classes em escala logarítmica

A escala logarítmica facilita a comparação visual entre as duas classes quando existe uma grande diferença entre suas frequências absolutas.

7. Fraudes acumuladas por ordem das transações

O eixo X representa a posição sequencial das transações no conjunto de dados. A posição 1 corresponde à primeira transação, a posição 2 à segunda transação, a posição 3 à terceira transação e assim sucessivamente.

O eixo Y representa a quantidade acumulada de fraudes. Sempre que uma observação apresenta TARGET_OMEGA = 1, o valor acumulado é incrementado em uma unidade. Quando a observação apresenta TARGET_OMEGA = 0, o valor acumulado permanece constante.
