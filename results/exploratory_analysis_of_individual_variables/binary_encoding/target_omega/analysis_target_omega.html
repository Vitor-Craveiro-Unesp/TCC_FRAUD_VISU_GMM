5. Shannon Entropy

Entropy = 0.047012 bits

For a binary variable, Shannon Entropy ranges from 0 to 1 bit.

  • Values close to 0 indicate a greater concentration of observations in a single class.
  • Values close to 1 indicate a greater balance between the two classes.
