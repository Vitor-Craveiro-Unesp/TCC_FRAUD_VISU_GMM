6. Unknown-category behavior

The encoding strategy uses:

handle_unknown="ignore"

A category known during encoder fitting activates exactly one of the existing binary features.

A category not observed during encoder fitting does not generate a new feature. Instead, all One-Hot columns associated with this original variable receive zero.

Category type Active columns Expected representation
Known category 1 One active binary column
Unknown category 0 All-zero vector
Important:

The unknown-category rate cannot be empirically calculated in this individual full-dataset analysis. To measure it correctly, the encoder must later be fitted only on the training data and then applied to separate test data. Categories present only in the test data will then be represented by an all-zero vector.

7. OHE representation uniqueness

Unlike Frequency Encoding, One-Hot Encoding preserves a unique representation for every category known during encoder fitting. Each known category activates a different binary column.
