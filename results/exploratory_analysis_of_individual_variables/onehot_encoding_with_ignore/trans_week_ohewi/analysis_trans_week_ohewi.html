6. Unknown-category behavior

The encoding strategy uses:

handle_unknown="ignore"

A weekday category known during encoder fitting activates exactly one binary feature.

An unknown category does not create a new feature. Instead, all One-Hot columns associated with the weekday variable receive zero.

Category type Active columns Expected representation
Known weekday 1 One active binary column
Unknown category 0 All-zero vector
Important:

The unknown-category rate cannot be empirically calculated in this individual full-dataset analysis. To measure it correctly, the encoder must later be fitted only on the training data and then applied to separate test data. A category present only in the test data would be represented by an all-zero vector.

7. OHE representation uniqueness

Each known weekday receives its own exclusive binary representation. Therefore, different known weekday categories do not collide after One-Hot Encoding.
